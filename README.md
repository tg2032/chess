# チェス

ブラウザで遊べるチェス。スマホ・タブレットのタッチ操作（タップ／ドラッグ）に対応。

## 遊ぶ

- 公開ページ: https://tg2032.github.io/chess/
- ローカル: このフォルダで `python -m http.server 8765 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8765/index.html` を開く

## 操作

- 駒をタップ→行き先をタップ、またはドラッグで移動
- 矢印キーでマス移動、Enter/Spaceで選択・移動、Escで選択解除
- 2人対戦 / CPU戦（やさしい・ふつう・むずかしい、白・黒選択可）
- ヒント、投了、待った、棋譜表示、サウンドON/OFFあり

## テスト

```sh
node test.js
```

合法手生成の perft 検証、特殊手（キャスリング、アンパッサン、プロモーション）、詰み・ステイルメイト・千日手・50手・駒不足、SAN表記、AIの合法性・強さ・速度、複数局の終了を検証します。

## 構成

- `game.js` — 盤面ロジックとAI（DOM非依存。Nodeとブラウザ、Web Workerで動作）
- `ui.js` — 盤面描画、タップ／ドラッグ入力、手番進行、AI連携
- `index.html` / `style.css` — 画面とスタイル
- `manifest.json` / `icon.svg` — PWA用
