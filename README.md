# チェス（Chess）

ブラウザで遊べるチェス。スマートフォン・タブレットのタッチ操作（タップ／ドラッグ）に対応しています。

**遊ぶ → https://tg2032.github.io/chess/**

## 機能

- **CPU戦**（やさしい / ふつう / むずかしい）と **2人対戦**（同じ端末で交互に）
- 全ルール対応：キャスリング、アンパッサン、プロモーション、ステイルメイト、千日手、50手ルール、駒不足
- 反復深化のαβ探索 + 静止探索、キラームーブ／ヒストリーによる手の並べ替え、千日手を考慮した評価
- CPUの思考は Web Worker で実行（盤面が固まりません）
- ヒント（常に「むずかしい」相当で探索）、戻る（`Ctrl+Z` / `⌘Z`）、投了、棋譜（SAN）、取った駒表示
- タップ→タップ、ドラッグ、キーボード（矢印キー + Enter/Space）で操作
- 効果音（Web Audio）、PWA（ホーム画面に追加・オフライン対応）

## ローカルで遊ぶ

静的ファイルだけで動きます。CPUの思考を別スレッドで動かすには HTTP サーバー経由で開いてください。

```bash
python -m http.server 8765 --bind 127.0.0.1
# → http://127.0.0.1:8765/index.html
```

`index.html` を直接開いても遊べます（その場合、思考は同じスレッドで動きます）。

## テスト

```bash
node test.js
```

perft による合法手生成の検証、特殊手、SAN、AI の強さ（hard > normal > easy）、思考時間、全自動対局の終局までを確認します。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `game.js` | ルール・評価・探索（DOM非依存。ブラウザ／Node／Worker で共用） |
| `ui.js` | 画面描画、入力、CPUのスケジューリング |
| `index.html` / `style.css` | 画面 |
| `sw.js` / `manifest.json` | PWA（オフライン対応） |
| `test.js` | Node 用テスト |
